## Reading the references

Source paths inside these documents use the combined project layout with sibling `pea-backend` and `pea-frontend` directories. Unqualified backend module paths refer to `pea-backend`. The same documentation is included in both component repositories so either repository provides a readable entry point.

References to `reference_materials/`, the release manifest, the full submission checklist and the demo video describe the original submission workspace. Those additional release materials are not included in this documentation folder.

The verification limitations stated in the original documents remain part of that historical snapshot. Copying the documents does not constitute a new installation test, benchmark run, Agent validation or coursework submission.
